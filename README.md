# متجر أولغا — النسخة المفصولة والمنظّمة (OLGA Store)

تم تقسيم ملف متجر أولغا المدمج إلى هيكل احترافي منفصل بالكامل مع الحفاظ على جميع الميزات، السيرفرات، لوحة التحكم، المساعدة الذكية (شمس)، العرض ثلاثي الأبعاد، الخرائط، والطلبات.

---

## هيكل الملفات والمجلدات

```text
olga-store/
├── index.html                  # هيكل الصفحة فقط (بدون CSS أو JS أو بيانات مدمجة)
├── style.css                   # ملف التنسيق الرئيسي (يستورد جميع ملفات التنسيق بالترتيب الصحيح)
├── script.js                   # منطق المتجر الرئيسي (المنتجات، السلة، 3D، الدفع، الخرائط، لوحة التحكم)
├── css/
│   ├── base.css                # التصميم الأساسي والهوية البصرية لمتجر أولغا
│   ├── shams.css               # تنسيقات المساعدة الذكية شمس
│   ├── overlays.css            # تنسيقات المعرض والزخارف (Lookbook / Lightbox)
│   ├── checkout.css            # تنسيقات سلة التسوق وإتمام الطلب والخريطة وحالات الطلب
│   ├── responsive.css          # التجاوب مع الجوال والتابلت والشاشات المختلفة
│   ├── categories.css          # بطاقات التصنيفات وحركة السلة
│   ├── motion.css              # حركات الظهور والتمرير ودليل التسوق
│   └── shams-3d.css            # تنسيقات شمس داخل العرض ثلاثي الأبعاد
├── data/
│   ├── config.js               # إعدادات السيرفرات ولوحة التحكم والذكاء الاصطناعي وأرقام واتساب (مكان واحد للتعديل)
│   ├── assets-manifest.js      # خريطة مسارات جميع الصور والشعار
│   ├── products.js             # بيانات المنتجات والتصنيفات والمدن الأردنية والريلز

│   ├── shams-knowledge.js/.json# قاعدة معرفة شمس بالمتجر والمنتجات
│   ├── shams-poses.js/.json    # بيانات حركات ووضعيات شمس
│   ├── shams-dialogue.js       # نصوص جولة شمس ودليل شرح المنتجات
│   ├── shams-vox.js            # بيانات التزامن الصوتي وحركة الشفاه ومسارات الصوتيات
│   └── shams-xvox.js           # مسارات صوتيات شرح المنتجات ثلاثية الأبعاد
├── js/
│   ├── frame-governor.js       # منظم الأداء والإطارات على الهواتف
│   ├── overlays.js             # سكربت الزخارف والعناصر التفاعلية
│   ├── motion.js               # سكربت حركات التمرير
│   ├── shams.js                # محرك المساعدة الذكية شمس والصوت وحركة الشفاه والرسوم
│   ├── shams-ui.js             # سلوك شمس مع العرض 3D وفقاعة الكلام والتجاوب
│   └── lifestyle.js            # شبكة الهدايا وحركة البارالاكس ومعرض الصور Lightbox
└── assets/
    ├── icons/                  # أيقونة الموقع (favicon.svg)
    ├── images/
    │   ├── products/           # صور المنتجات المفرّغة (.webp)
    │   ├── gallery/            # صور المعرض والهيرو وإنستغرام (.webp)
```

## إعدادات السيرفرات ولوحة التحكم

تم تجميع جميع الروابط والمفاتيح في ملف واحد فقط وهو **`data/config.js`**:
- **`dbUrl` / `dbKey`**: رابط ومفتاح قاعدة بيانات لوحة تحكم أولغا (لجلب رسوم التوصيل وإرسال الطلبات عبر `place_order`).
- **`shamsApi`**: رابط خادم المحادثة الذكية والصوت الطبيعي لشمس (`olga-chat` و `olga-tts`).
- **`whatsappSupport` / `whatsappOrders`**: أرقام واتساب خدمة العملاء وتأكيد الطلبات.
- **`mapTilesUrl` / `geocodingBaseUrl`**: خوادم خرائط التوصيل وتحديد الموقع.

## طريقة التشغيل المحلي

بسبب وجود ملفات صوتية (`assets/audio/*.mp3`) يتم تحميلها عبر `fetch()` لمحرك التزامن الصوتي، يُفضّل تشغيل المشروع عبر خادم محلي (أو رفعه مباشرة على أي استضافة ويب مثل Netlify / Vercel / Cloudflare Pages / cPanel):

```bash
# باستخدام Python:
python3 -m http.server 8080

# أو باستخدام VS Code:
# اضغط بزر الفأرة الأيمن على index.html ثم اختر Open with Live Server
```
